# ACT 4 Change: #NoBullying website

Website of the Erasmus+ youth exchange in Bansko, Bulgaria, 5–15 October 2026.

Live site: https://alperenaslan27.github.io/Bansko-website/

## How to edit

- The whole site is one file: `index.html`.
- Put project outcome files (magazine PDF and other documents) in the `outcomes` folder.
- Videos go on YouTube; the site links to them.
- Every change you commit and push in GitHub Desktop goes live in about a minute.
